# Excel Sales Dashboard

## Project Overview

This project is an interactive Excel Sales Dashboard created using Pivot Tables, Pivot Charts, Slicers, and KPI cards.

The dashboard analyzes Superstore sales data to identify:

* Sales trends over time
* Category-wise sales performance
* Region-wise sales distribution
* Business insights

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting

## Dashboard Features

* Total Sales KPI
* Total Orders KPI
* Monthly Sales Trend Analysis
* Sales by Category
* Sales by Region
* Interactive Slicers
* Business Insights Section

## Key Insights

* Technology category generated highest sales
* Sales increased significantly in 2018
* West region showed strong performance
